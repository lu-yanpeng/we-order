### 弹窗自动高度与触摸滚动（已解决）

#### 问题
弹窗内规格区域需要：内容少时高度自适应，内容多时封顶 75vh 并可手指滑动滚动。尝试了多种方案后最终解决。

#### 排查过程

1. **纯 CSS `overflow-y: auto`（失败）**：flex 布局 + `overflow-y: auto` 在开发者工具中鼠标滚轮可滚动，但真机上手指无法滑动
2. **`scroll-view` + JS 动态高度（可行但复杂）**：`onMounted` 时用 `uni.createSelectorQuery()` 测量 header/footer 高度，计算 `scroll-view` 的 `max-height`。真机可滑动，但后期切换商品时需要重新计算
3. **参考旧项目 food-flow**：发现旧项目 `product-specs` 组件用 `t-dialog` + `overflow-y: auto` 实现了同样的功能且真机正常，于是对比了 `t-dialog` 和 `t-popup` 的源码

#### 根因

TDesign `t-popup` 组件源码（`@tdesign/uniapp/dist/popup/popup.vue`）中，当 `preventScrollThrough` 为 `true`（默认值）时，内容容器会加上 `@touchmove.stop.prevent="noop"`，**直接阻止了所有触摸滑动事件**，导致子元素的 `overflow-y: auto` 在真机上无法触发滚动。

```html
<!-- t-popup 源码，preventScrollThrough=true 时走此分支 -->
<view v-if="innerPreventScrollThrough"
      @touchmove.stop.prevent="noop">  <!-- 🔴 吞掉了所有 touchmove -->
  <slot />
</view>

<!-- preventScrollThrough=false 时走此分支 -->
<view v-else>  <!-- ✅ 不拦截 -->
  <slot />
</view>
```

而 `t-dialog` 源码中完全没有 `touchmove` 拦截，所以旧项目 food-flow 的 `overflow-y: auto` 能正常工作。

#### 最终方案

纯 CSS 方案，无需 JS 计算：

1. `t-popup` 添加 `:prevent-scroll-through="false"`，解除 touchmove 拦截
2. 弹窗布局使用 flex column：
   - `.spec-content`：`display: flex; flex-direction: column; max-height: 75vh`
   - `.spec-header`：`flex-shrink: 0`（固定）
   - `.spec-scroll-wrapper`：`flex: 1 1 auto; min-height: 0; overflow-y: auto; -webkit-overflow-scrolling: touch; overscroll-behavior: contain`（自适应 + 可滚动）
   - `.spec-footer`：`flex-shrink: 0`（固定）
3. `overscroll-behavior: contain` 防止滚动链传播（实测未出现滚动穿透）
