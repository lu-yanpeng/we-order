# 分包组件（Subpackage Component）使用指南

## 背景

微信小程序的分包机制要求非主包代码必须在 `subPackages` 中声明。当主包页面需要引用分包中的组件时，需要使用 `componentPlaceholder` 机制实现按需加载。

## 创建步骤

### 1. 创建组件文件

在 `src/sub-components/` 下按组件名创建目录，组件文件命名为 `index.vue`：

```
src/sub-components/checkout-bar/index.vue
```

### 2. 注册分包

在 `pages.json` 的 `subPackages` 中添加分包声明，`pages` 设为空数组：

```json
{
  "root": "sub-components",
  "pages": []
}
```

### 3. 配置 componentPlaceholder

在引用该组件的页面配置中，添加 `componentPlaceholder` 映射，指定占位组件（通常为 `view`）：

```json
{
  "path": "pages/home/index",
  "style": {
    "navigationBarTitleText": "经典点单",
    "componentPlaceholder": {
      "checkout-bar": "view"
    }
  }
}
```

### 4. 启用用时注入

在 `manifest.json` 的 `mp-weixin` 中添加：

```json
{
  "lazyCodeLoading": "requiredComponents"
}
```

### 5. 在页面中使用

正常 import 并使用，uniapp 编译器会自动处理跨分包引用：

```vue
<script setup lang="ts">
import CheckoutBar from '@/sub-components/checkout-bar/index.vue'
</script>

<template>
  <checkout-bar />
</template>
```

## 运行时行为

- 分包未下载时，`view` 占位组件渲染（空节点）
- 分包下载完成后，自动替换为真实组件
