这个子项目是微信小程序的前端项目，根据opendesign设计好的原型html搭建，参考了星巴克的设计规范

## 快速启动

以开发模式启动，运行命令打包好项目后需要手动在微信开发者工具中导入`dist/dev/mp-weixin`目录。修改文件后会自动重新打包，在开发者工具中清空缓存刷新就能看到最新效果。

```shell
pnpm install
pnpm dev:mp-weixin
```
