## 加载态复验（慢 3G）

前置：开发者工具网络限速「慢 3G」；**不在代码中加延迟**；建议先「清缓存并重启」。

- [x] 点餐 tab 首屏：约 250ms 后出现目录双栏骨架；加载完成即替换；不限速时不闪
- [x] 订单 tab 首屏（有数据）：订单卡片骨架（与当前卡片结构一致）；不限速时不闪
- [x] 后续刷新（切 tab / 回前台 / 下拉 / 轮询）静默更新、不回骨架
- [x] 确认订单页：门店卡首读遮罩（250ms 延迟、白字 loading、完成即撤）；与支付 loading 不叠加；门店失败走卡片内「文案 + 重试」、重试不弹遮罩
- [x] 订单详情：首读全屏遮罩（250ms 延迟、完成即撤）；重试 / 下拉 / 轮询读取不弹遮罩

## 常用构造 SQL（附录）

- 批量建单（分页前置；同批键重复执行不会重复建单，换前缀即可加批）：

```sql
select public.create_order_for_user(
  '<本人 user_id>'::uuid,
  '[{"product_id":"00000000-0000-4000-8000-000000000203","quantity":1,"selections":{}}]'::jsonb,
  'dinein', '无备注要求', 'bulk-' || g::text
) from generate_series(1, 25) g;
```

本人 `user_id`：`select user_id, created_at from public.wechat_identities order by created_at desc;`

- 售罄 / 下架构造与还原：

```sql
update public.products set availability = 'sold_out' where id = '<商品 id>';
update public.products set availability = 'delisted' where id = '<商品 id>';
update public.products set availability = 'on_sale'  where id = '<商品 id>';   -- 还原
```
